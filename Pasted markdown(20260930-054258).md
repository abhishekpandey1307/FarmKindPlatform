# 1. PRODUCT

## Product name

**FarmKind**

## Product positioning

FarmKind is an **AI decision-and-action platform for small and marginal Indian farmers**.

It is not merely:

- a sensor dashboard
- a weather app
- a marketplace
- a solar marketplace
- an FPO app
- a farmer social network
- a post-harvest dashboard
- a chatbot

These are supporting capabilities.

The central product is:

> **One evolving FarmState + one AI Decision Engine that understands what is happening on the farm, determines what matters next, connects the farmer with affordable resources, recommends or executes permitted actions, verifies outcomes, and measures impact.**

Core loop:

**SENSE → UNDERSTAND → DECIDE → ACT → VERIFY → MEASURE → REPEAT**

Universal event-driven loop:

**SIGNAL → CONTEXT → ANALYSIS → OPTIONS → OPTIMAL ACTION → EXECUTION → VERIFICATION → IMPACT**

Do not change this product thesis.

# 23. FARMSTATE — IMPLEMENT FOR REAL

Create a central strongly typed FarmState.

Suggested TypeScript structure:

```ts
type SourceType =
  | "REAL"
  | "REFERENCE"
  | "CALCULATED"
  | "ASSUMED"
  | "SIMULATED"
  | "AI_DERIVED";

interface DataPoint<T> {
  value: T | null;
  unit?: string;
  timestamp: string;
  sourceType: SourceType;
  confidence?: number;
}

interface Farmer {
  farmerId: string;
  name: string;
  location: string;
  preferredLanguage: string;
  farmIds: string[];
  createdAt: string;
}

interface Farm {
  farmId: string;
  location: string;
  areaAcres: number;
  crop: string;
  cropStage: string;
  plantingDate?: string;
  irrigation: WaterState;
  energy: EnergyState;
  soil: SoilState;
  sensors: Sensor[];
  weather: WeatherState;
  harvest: ProduceBatch[];
  market: MarketState;
  logistics: LogisticsState;
  connectedSystems: ConnectedSystems;
}

interface WaterState {
  irrigationMethod: string;
  irrigationFrequency: string;
  estimatedWaterPerEvent: number;
  estimatedDailyWaterUse: number;
  estimatedSeasonalWaterUse: number;
  lastIrrigation?: string;
  source: SourceType;
}

interface EnergyState {
  primarySource: string;
  secondarySource?: string;
  pumpType: string;
  estimatedConsumption: number;
  consumptionUnit: string;
  energyCost: number;
  source: SourceType;
}

interface SoilState {
  moisture: number | null;
  temperature: number | null;
  sensorStatus: "NOT_CONNECTED" | "CONNECTING" | "LIVE" | "STALE";
  timestamp?: string;
  source: SourceType;
}

interface WeatherState {
  temperature: number;
  rainfall: number;
  humidity: number;
  rainProbability: number;
  heatRisk: string;
  forecastConfidence: number;
  timestamp: string;
  source: SourceType;
}

interface ConnectedSystems {
  solar: boolean;
  soilSensor: boolean;
  smartIrrigation: boolean;
  automation: boolean;
}

```

Keep the architecture extensible.
